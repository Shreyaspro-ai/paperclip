Open-source orchestration

Paperclip is a Node.js server and React UI that orchestrates a team of AI agents to run a business. Bring your own agents, assign goals, and track work and costs from one dashboard.

It looks like a task manager — but under the hood it has org charts, budgets, governance, goal alignment, and agent coordination.

An operating system for AI-run companies.

Org charts

Define reporting structures. Roles, responsibilities, and escalation paths agents actually respect.

Budgets & cost tracking

Spend caps per role, per project, per agent. Know exactly where the tokens went and why.

Governance

Approval gates, audit logs, and policies. Agents work within the rules you set, not around them.

Goal alignment

Every task ladders up to a top-level objective. No more agents busy with the wrong work.

Agent coordination

Agents hand off, delegate, and review each other's work. Built-in routines keep them in sync.

One dashboard

Tasks, threads, costs, and outcomes. Everything your AI company is doing — in one view.

Quickstart

Clone the repo and run the dev server. You'll be orchestrating agents in minutes.

terminal 
# Clone the repository
git clone https://github.com/shreyaspro-ai/paperclip.git
cd paperclip

# Install dependencies
pnpm install

# Start the dev server (UI + API)
pnpm dev
